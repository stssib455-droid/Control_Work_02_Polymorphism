# Контрольная работа №2: ПО объектов наземной инфраструктуры
**Тема:** Абстрактные и виртуальные классы в архитектуре БПЛА
**Специальность:** 27.03.05 Инноватика
**Вариант:** 2 для всех заданий (UAV: Quad/Hexa/Octocopter, Sensors: GPS/GLONASS/VO, Nav: Failover GPS->INS->Visual, Integration: Autopilot 5 сценариев).

## Инструкция по запуску:
1. Распакуйте архив.
2. Откройте Qt Creator.
3. Нажмите **File -> Open File or Project...** и выберите файл `CMakeLists.txt`.
4. Нажмите **Configure Project**.
5. Нажмите `Ctrl+R` (или зеленую кнопку «Play») для сборки и запуска.
